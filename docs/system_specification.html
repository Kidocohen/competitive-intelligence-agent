Competitive Intelligence Multi-Agent System

מגיש: עידו כהן

  • מהות הפרויקט: מערכת אוטונומית מבוססת סוכנים (Multi-Agent System) לאיסוף, ניתוח וסיכום של מודיעין תחרותי.
  • הפתרון הטכנולוגי: מנוע LangGraph המנהל תהליך מחקר מלא - החל משליפת נתונים ועד הפקת דוח אסטרטגי.
  • ערך עסקי: אוטומציה של תהליכים ידניים, חיסכון בזמן אנליסטים, ומזעור טעויות אנוש באיסוף נתונים.
הערת דובר: "בניתי את המערכת מתוך הבנה שארגונים טובעים במידע. המערכת מחליפה את החיפוש הידני בסוכן חכם שיודע לתכנן מחקר, להפעיל כלים ולספק שורת מחץ אסטרטגית."

ארכיטקטורת המערכת (5 Nodes)

  • 1. Input Guardrail: שומר סף הקולט את השאילתה, מסנן נושאים לא רלוונטיים וחוסם ניסיונות הזרקת פרומפטים (Prompt Injections).
  • 2. Research Planner: מתכנן המחקר. בונה מראש את אסטרטגיית איסוף המודיעין ומגדיר לסוכן את חוקי העבודה.
  • 3. Agent Reasoning: המוח המרכזי. מחליט איזה כלי להפעיל, מנתח את התוצאות, ובסיום מסנתז ומסכם את המידע לדוח הסופי.
  • 4. Tool Execution: הזרוע הביצועית המפעילה בפועל את חיפושי המסד וה-Webhooks.
  • 5. Output Guardrail: בקרת האיכות הסופית. מוודאת שעומק התוכן מספק, שאין שאריות קוד, ושהדוח מגובה בעובדות (מניעת Hallucinations).

אסטרטגיית RAG ועיבוד נתונים

  • מסד נתונים וקטורי: אינטגרציה מול Qdrant לאחסון סודי של דוחות מודיעין פנימיים.
  • אסטרטגיית חיתוך (Chunking): חלוקת מסמכי מקור באמצעות RecursiveCharacterTextSplitter למקטעים של 500 תווים, עם חפיפה של 80 תווים לשמירה על הקשר רציף.
  • מודל הטמעה (Embeddings): מודל text-embedding-3-small של OpenAI, המייצר וקטורים של 1536 ממדים.
  • חישוב מרחק וסינון: שימוש ב-Cosine Similarity, בשילוב חילוץ Metadata דינמי המאפשר לסנן תוצאות לפי שם חברת המטרה.
הערת דובר: "בחרתי בחפיפה של 80 תווים בחיתוך הטקסט כדי להבטיח שמשפטים ורעיונות עסקיים קריטיים לא ייחתכו באמצע, מה שמבטיח שליפה סמנטית סופר-מדויקת מ-Qdrant."

אוטומציה וכלים חיצונים (n8n)

  • ארגז כלים כפול: שימוש ב-search_internal_intelligence למידע ארגוני מסווג, וב-fetch_external_market_data למודיעין זמן אמת.
  • Microservices באמצעות n8n: המערכת פונה לשרת אוטומציה חיצוני המאזין ל-Webhook (בנתיב /market-intelligence).
  • לוגיקת חיפוש: הפעלת מנוע Tavily בזמן אמת לאיסוף חדשות חמות ועדכוני שוק.
  • העשרת נתונים (Enrichment): ה-Payload שחוזר מהאוטומציה כולל לא רק את המידע, אלא גם ציון סנטימנט המקל על ניתוח המגמה.

סביבת הרצה (Deployment)

  • קונטיינרים: המערכת ארוזה ומבודדת לחלוטין באמצעות docker-compose.yml להבטחת עבודה יציבה בכל סביבה.
  • Backend (Flask): שרת עוטף הרץ על פורט 5000, מנהל את ה-LangGraph ומספק גישה דרך נתיב /api/research.
  • Frontend (Streamlit): ממשק לקוח אינטראקטיבי הרץ על פורט 8501, ומאפשר חוויית שיחה חלקה מול הסוכן.
  • הרצה פשוטה: הקמת כל סביבת הפרודקשן מבוצעת באמצעות פקודה בודדת: docker-compose up --build.
